这类介词后面永远跟第三格。

支配三格或四格的介词（Wechselpräpositionen）

这类介词也叫“动四静三”介词。同一个介词，根据表达含义的不同，决定用三格还是四格。

  • Wo?（在哪里？）表示位置、静态 -> 第三格（Dativ）
  • Wohin?（去哪里？）表示方向、动态 -> 第四格（Akkusativ）

9 大“静三动四”介词：an, auf, hinter, in, neben, über, unter, vor, zwischen

现在完成时（Perfekt）

基本结构：haben / sein + Partizip II（第二分词）

助动词在句子第二位根据主语变位，第二分词放在句末。

主语位置 2（助动词）中间成分句末（第二分词）
Ichhabeeinen Apfelgegessen.
Eristnach Hausegegangen.

用 sein 的常见情况：

  • 表示位置移动的不及物动词：gehen, fahren, kommen, laufen, fliegen
  • 表示状态变化：aufwachen, einschlafen, sterben, werden
  • 特殊词：sein, bleiben, passieren

第二分词构成：

  • 规则变化：ge + 词干 + t，例如 machen -> gemacht
  • 词干以 -t/-d 结尾：常加 -et，例如 arbeiten -> gearbeitet
  • 以 -ieren 结尾：不加 ge，直接 + t，例如 telefonieren -> telefoniert
  • 可分动词：前缀 + ge + 词干 + t，例如 einkaufen -> eingekauft

mit + 交通工具：用第三格
